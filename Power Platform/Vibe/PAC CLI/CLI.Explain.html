CLI for Microsoft 365

What it is

CLI for Microsoft 365 is an open-source cross-platform command-line tool maintained by the Microsoft 365 developer community. It automates Microsoft 365 workloads with a consistent command structure.

m365 <workload> <resource> <operation> [options]
m365 status
m365 spo list add --title "Example" --webUrl "https://contoso.sharepoint.com/sites/demo"
m365 flow list --environmentName "Default-..."

Where to get it

  • Documentation: pnp.github.io/cli-microsoft365
  • npm package: @pnp/cli-microsoft365
  • GitHub source and releases: pnp/cli-microsoft365

For a one-off invocation without a global installation:

npx --yes --package @pnp/cli-microsoft365@11.11.0 m365 version

For a global installation:

npm install -g @pnp/cli-microsoft365
m365 version

Node.js and npm are required. Download Node.js from nodejs.org.

First-use setup and help

m365 setup
m365 help
m365 <command> --help
m365 version
Use built-in help before a write operation. It documents the exact installed version's required permissions, parameters, examples, and output options.

Authentication

m365 login --authType deviceCode --appId <APPLICATION-CLIENT-ID>
m365 status
m365 logout

<APPLICATION-CLIENT-ID> is the Application (client) ID of an Entra app registration configured as a public client. It identifies the CLI to Entra ID. The device-code browser prompt signs in as the user and obtains delegated permissions; it does not use a client secret.

Use an authentication method appropriate to the security model. Do not put passwords, access tokens, or client secrets in scripts or workspace files.

Power Platform CLI (pac)

What it is and where to get it

Power Platform CLI is Microsoft's official CLI for Power Platform development and administration. It works with Dataverse environments, solutions, Canvas Apps, connectors, Power Pages, Power Apps component framework controls, and more.

  • Install Power Platform CLI
  • Power Platform CLI command reference
pac help
pac <group> help
pac <group> <command> help

Operations used in this workspace

Command groupOperations used or relevant
pac authCreate, list, and select Dataverse authentication profiles
pac envInspect, list, select, and query Dataverse environments
pac solutionInitialize, pack, import, export, list, and manage Dataverse solutions
pac canvasList and download Canvas Apps; unpack and pack .msapp source files
pac connectionList and manage Power Platform connector connections
pac auth list
pac env who
pac solution list
pac canvas list
pac connection list
Canvas App limitation: the installed PAC CLI can download, unpack, and pack .msapp files, but it cannot upload or overwrite a Canvas App in the environment. Use Power Apps Studio to import, save, and publish a packed app.

PnP.PowerShell

What it is and where to get it

PnP.PowerShell is a PowerShell module for SharePoint, Microsoft Teams, Microsoft 365 Groups, Planner, and related Microsoft 365 services.

  • Installing PnP PowerShell
  • PnP PowerShell cmdlets

The current version requires PowerShell 7.4 or later. This computer has PowerShell 7.6.5:

& 'C:\Program Files\PowerShell\7\pwsh.exe'

Install-Module PnP.PowerShell -Scope CurrentUser
Import-Module PnP.PowerShell

Relevant operations

CmdletPurpose
Connect-PnPOnlineAuthenticate to a SharePoint site
Get-PnPWebVerify the active site connection
New-PnPListCreate a SharePoint list
Add-PnPFieldAdd a list or site column
Add-PnPListItemCreate a list item
Get-PnPListRetrieve list details
Get-PnPListItemRetrieve list items

PnP.PowerShell is a good alternative when a PowerShell-native script is preferred. In this session, its interactive device-login prompt did not work through the terminal host, so CLI for Microsoft 365 is the more practical path after an Entra app ID is supplied.

Which tool should I choose?

TaskPreferred tool
Create SharePoint lists, columns, and fictional list dataCLI for Microsoft 365 or PnP.PowerShell
Create a new Power Automate cloud flowPower Automate web designer
List, export, enable, or disable an existing flowCLI for Microsoft 365
Create/import/export a Dataverse solutionPower Platform CLI
Download/unpack/edit/pack a Canvas App filePower Platform CLI
Import and publish a Canvas AppPower Apps Studio
For all tools, start with the narrowest help command, authenticate with least privilege, and use JSON output when a script needs to read command results.
